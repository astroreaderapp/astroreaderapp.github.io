# Sitio web de Astro Reader

Página de inicio y política de privacidad de Astro Reader (español e inglés), publicadas con GitHub Pages.

- `index.html` y `privacidad.html`: español.
- `en/index.html` y `en/privacy.html`: inglés.
- `estilos.css`: diseño (colores de la app, modo claro y oscuro).
- `img/`: logo, iconos e imagen para compartir enlaces.
- `fuentes/`: Inter y Outfit (licencia SIL Open Font License).

Para poner el enlace de Google Play, busca `google-play` en `index.html` y `en/index.html`.
